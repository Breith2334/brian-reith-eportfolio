Event Reminder App

This artifact demonstrates my database development skills through an Android application that stores and manages event information using SQLite.

Original Code

The original application allowed users to manage event information. Event data was primarily maintained in an in-memory list, which meant that changes could be lost when the application closed.

View Original Code

Enhanced Code

The enhanced application uses SQLite to persist event information. The DatabaseHelper class manages database operations, including adding, retrieving, updating, and deleting events. The enhancement also supports searching for events stored in the database.
