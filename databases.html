Databases

Event Reminder App

This artifact demonstrates my database development skills through an Android application that manages event information using SQLite. I selected this project for my Computer Science ePortfolio because it highlights my ability to design and implement database solutions that improve data management, persistence, and user functionality. The project also demonstrates my understanding of database operations, data storage, and how databases can support real-world applications.

Original Code

The original application allowed users to create and manage event information, but the data was stored in an in-memory list. Because the information was only stored while the application was running, all event data was lost when the application was closed. While the original version provided basic event management functionality, it lacked a permanent storage solution and offered limited data retrieval capabilities.

View Original Code

Enhanced Code

For my enhancement, I implemented SQLite database support to provide persistent storage for event information. I created and integrated a DatabaseHelper class to manage database operations, including adding, retrieving, updating, and deleting event records. This enhancement allows event data to remain available even after the application is closed and reopened, making the application more practical and reliable for users.

In addition to implementing database persistence, I added search functionality that allows users to locate specific events stored in the database. This feature improves the user experience by making it easier to retrieve relevant information without manually browsing through all stored records. The enhancement demonstrates how database queries can be used to efficiently search and filter data based on user input.

Skills and Knowledge Gained

Through this project, I gained experience working with SQL queries, database design, and CRUD operations, which include create, read, update, and delete functions. I learned how applications interact with databases to store and retrieve information and how proper database management helps improve data integrity and long-term usability. I also strengthened my understanding of how different software components work together to support application functionality.

Testing and Results

After implementing the enhancement, I tested the application to verify that users could successfully add, edit, delete, and search for events while maintaining data between application sessions. The database correctly stored event information, and the search functionality returned matching records as expected. These results confirmed that the application could reliably manage event data while providing improved functionality compared to the original implementation.

Challenges and Lessons Learned

Working on this enhancement helped me better understand the importance of persistent data storage in software development. I learned that storing information in memory may be sufficient for simple applications, but databases provide a more reliable solution for applications that require long-term data management. I also learned the importance of connecting database methods correctly to the application's user interface and testing each operation to ensure that data is handled consistently.

Overall, this project strengthened my skills in database development, SQL, application design, and testing while demonstrating how database enhancements can improve both functionality and user experience. This experience will help me apply database concepts to future software development projects that require reliable data storage, retrieval, and management.
