Treasure Hunt Game

This artifact demonstrates my skills in algorithms, data structures, and artificial intelligence through a Treasure Hunt Game. The game uses a reinforcement learning agent to help a pirate navigate a maze and find treasure.

Original Code

The original project provided a maze environment and a reinforcement learning model. The pirate agent learned to select actions to navigate the maze and reach the treasure.

View Original Code

Enhanced Code

The enhanced version improves the play_game function by adding a maximum step limit to prevent endless loops, converting the game state into a NumPy array with the appropriate data type, and formatting the state for model predictions. These changes improve reliability and help the pirate agent complete the game efficiently.
