# Original Travlr Getaways Application

## Overview
The original Travlr Getaways application was developed as part of my Computer Science coursework. It is a travel booking web application that demonstrates full-stack software development using a combination of front-end and back-end technologies.

## Purpose
This artifact serves as the baseline for my CS 499 Capstone ePortfolio. It demonstrates my initial knowledge of software design and engineering and provides a foundation for evaluating the improvements made in the enhanced version.

## Technologies Used

- Node.js

- Angular

## Original Functionality
The original application includes a customer-facing travel website and an administrative interface for managing travel information. It uses server-side routes, controllers, models, and views to support the application's functionality.
