About Me

My name is Brian Reith, and I am completing my Bachelor of Science in Computer Science at Southern New Hampshire University (SNHU). Over three years in the program, I have built skills in full-stack web development, mobile application development, Python programming, and reinforcement learning.

What I Have Learned

The three most important concepts and skills I have gained are:

Software architecture and design patterns

I learned the importance of modular design, separation of concerns, and building scalable applications. These principles shape how I design both mobile and web-based systems.

Algorithms and data structures

I gained experience analyzing efficiency, optimizing performance, and implementing data structures and algorithms in Python and Java. This helps me weigh trade-offs and choose effective solutions.

Database design and secure data handling

I developed skills in MongoDB schema design, indexing, and secure CRUD operations. Knowing how to manage and protect data is essential for building reliable production applications.

Skills My Enhancements Demonstrate

My enhancements are designed to meet all five course outcomes:

  • Communication and collaboration: my code review video and written narratives.
  • Algorithmic reasoning: my reinforcement learning artifact, which implements and evaluates multiple exploration strategies.
  • Secure software engineering: input validation, role-based access control (RBAC), credential management, and audit logging in my mobile and full-stack projects.
  • Modern tools and techniques: MVVM architecture, Hilt dependency injection, NumPy optimization, and Mongoose middleware.
  • Security mindset: identifying and reducing potential vulnerabilities in both mobile and web applications.

Career Goals

These skills support my goal of becoming a developer who builds secure, efficient, and well-designed applications across mobile and web platforms. Using MVVM and Hilt in my Android project shows I can build modern, maintainable mobile apps. Adding RBAC, audit logging, and secure credential handling to my full-stack application shows I can build secure, scalable systems. My reinforcement learning work strengthens my analytical and problem-solving skills by requiring me to evaluate algorithms and their trade-offs.

Together, these enhancements support my specialization in secure full-stack and mobile software development. They follow current industry standards for mobile development and address real-world security concerns in system design, and they show my commitment to building expertise in secure, modern, and well-architected applications.
