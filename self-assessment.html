Professional Self-Assessment

Throughout the Bachelor of Science in Computer Science program at Southern New Hampshire University, I have developed my technical knowledge, problem-solving abilities, and understanding of software development. My coursework has helped me understand how software engineering, algorithms and data structures, databases, and security work together to create effective computing solutions. Completing this ePortfolio has allowed me to reflect on my progress, improve existing projects, and demonstrate the skills I have gained throughout the program.

My goal is to continue developing my technical abilities and apply my knowledge to real-world challenges. I have learned that successful software development requires more than writing code. It also requires planning, testing, documentation, security awareness, and the ability to communicate technical information clearly. The three artifacts in this portfolio demonstrate my growth and my ability to analyze existing applications, identify opportunities for improvement, and implement enhancements.

Computer Science Growth

My experience in the Computer Science program has strengthened my ability to approach problems logically and develop solutions through a structured process. I have learned the importance of breaking complex problems into smaller tasks, evaluating different approaches, testing solutions, and making improvements based on results. These skills have helped me become more confident when working with programming languages, application development tools, and data management systems.

I have also developed a greater appreciation for collaboration and communication. Software developers must understand project requirements, consider the needs of users, and explain technical decisions to different audiences. Documenting my work and presenting my projects through this ePortfolio has helped me practice communicating my technical skills and explaining the reasoning behind my decisions.

Software Engineering

Software engineering has taught me the importance of application structure, maintainability, usability, and testing. My Travlr Getaways project demonstrates my experience working with a web application that uses front-end and back-end technologies to support travel-related information. Through this project, I developed a better understanding of how application components work together and how organized code supports future development.

Enhancing this artifact helped me recognize the importance of reviewing existing code before making changes. I learned to identify areas where functionality, organization, and maintainability could be improved. These experiences reinforced the value of planning changes carefully, testing functionality, and considering how software design decisions affect the overall user experience.

Algorithms and Data Structures

My Treasure Hunt Game project demonstrates my understanding of algorithms, data structures, and problem-solving through reinforcement learning. The project uses a pirate agent that learns to navigate a maze and reach a treasure. Working with this project helped me understand how an algorithm can evaluate possible actions and use experience to improve decision-making.

Enhancing the game logic strengthened my understanding of program flow, state management, action selection, and termination conditions. I also learned the importance of testing an algorithm to confirm that it behaves as expected and handles different outcomes appropriately. This project demonstrated how algorithmic thinking can be applied to a practical problem and reinforced the importance of evaluating correctness and efficiency when developing computing solutions.

Database Development

My Event Reminder App demonstrates my experience developing an Android application that manages event information. The project uses an SQLite database to store information and supports functionality such as user account creation, login, and event management. This artifact helped me understand how applications interact with databases to store, retrieve, update, and delete information.

Enhancing the application strengthened my understanding of database design, SQL operations, and the relationship between application logic and persistent data storage. I also worked on improving event management functionality so that information could be retrieved from the database rather than existing only temporarily in the application interface. This experience reinforced the importance of data integrity, reliable storage, and testing database operations to ensure that information remains consistent.

Security

Security is an important consideration throughout the software development process. My coursework and application development experience have helped me recognize the importance of protecting user information, validating input, and limiting access to application functionality when appropriate. Applications that manage user accounts or personal information must be designed with security in mind rather than treating it as an afterthought.

My Event Reminder App provided an opportunity to consider how login functionality, account information, database operations, and Android permissions affect application security. I recognize that storing passwords in plain text is not appropriate for a production application. Secure password hashing, careful input validation, and appropriate database access controls are important considerations for future improvements. I also learned that application permissions should be requested only when necessary and that users should understand why those permissions are needed. These lessons will guide my approach to building more secure and reliable applications.

Professional Goals

My professional goal is to continue growing as a technology professional and apply my Computer Science education to practical business and technical challenges. I am particularly interested in opportunities that allow me to combine analytical thinking, problem-solving, software development, and process improvement. I want to continue strengthening my programming skills while learning new technologies and development practices.

Completing this ePortfolio has helped me recognize the value of continuous learning, attention to detail, and persistence when solving technical problems. Each artifact represents a different aspect of my development: software engineering through Travlr Getaways, algorithmic problem-solving through the Treasure Hunt Game, and database development through the Event Reminder App. Together, these projects demonstrate my ability to work across different areas of computer science and improve existing solutions.

As I move forward professionally, I intend to continue developing my skills in software design, algorithms, databases, testing, and security. I will also continue improving my ability to communicate technical concepts, collaborate with others, and make informed decisions about technology. I view this ePortfolio as evidence of my growth and as a foundation for continued professional development throughout my career.
